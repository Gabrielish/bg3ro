# Scope

This repository is the BG3 Romanian translation showcase website. Do not modify the installed game, translation packages, item-order mod, Script Extender settings, or unrelated repositories.

The owner explicitly requests direct commit/push of requested website changes to GitHub. Deploy on GitHub Pages at https://gabrielish.github.io/bg3ro/ (main / root). Do not create a separate hosting site.

Preserve relative asset URLs, responsive layouts, Romanian diacritics, keyboard access and reduced-motion handling. Test browser interactions and mobile layout when changing the UI. Do not add unverified progress numbers, finished-feature claims, invented testimonials, or mod binaries. Download links point to https://www.nexusmods.com/baldursgate3/mods/24379 .
