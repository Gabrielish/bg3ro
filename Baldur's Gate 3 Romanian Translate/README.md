# Arhive BG3RO

Arhivele traducerii și ale modulelor suplimentare se încarcă din tabul Descărcări, folosind contul Discord al proprietarului.

Un fișier cu același nume este înlocuit printr-un commit GitHub. Butoanele de descărcare sunt legate de commitul versiunii publicate, astfel încât versiunile anterioare să nu descarce accidental o arhivă nouă.

Limita încărcării din site: 20 MB per arhivă ZIP, 7z sau RAR. Nicio cheie de acces nu se salvează în acest folder sau în codul public.
